TemplateLab è un marketplace di template digitali costruito con Next.js, Stripe (pagamenti), Clerk (auth) e Claude AI (Studio AI integrato per personalizzazione template).

**Differenziatore principale**: Studio AI powered by Claude per personalizzare i template — su Gumroad/Etsy si vende il template base; su TemplateLab il cliente paga anche per la personalizzazione AI.

**Due macro-categorie:**
1. UI Templates — HTML standalone con Tailwind CSS (landing page, hero, pricing, dashboard, ecc.)
2. AI Prompt Templates — file .txt (cold email B2B, product description, system prompt AI)

**Why:** L'utente vuole costruire una strategia di distribuzione multi-piattaforma (Etsy + Gumroad) usando quelle come top-of-funnel verso TemplateLab.
