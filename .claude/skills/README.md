# Vendored skills

Taken from [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT, © 2026 Emil Kowalski;
licence in `LICENSE-emilkowalski-skills.txt`), copied unmodified on 2026-10-17:

| Skill | Use it for |
| --- | --- |
| `emil-design-eng` | UI polish and animation decisions: should it animate, easing, duration, press feedback |
| `animation-performance` | Animations that drop frames; what to animate; blur cost |
| `apple-design` | Materials and depth (glass), springs, interruptibility, reduced motion |
| `mobile-native` | Making the site feel native on a phone: hover, tap, `dvh`, 16 px inputs, safe areas |
| `break-ui` | Worst-case data: long names, empty lists, huge numbers |
| `review-animations` | A strict review of the motion in a change |

They are third-party guidance: they never override the rules in `CLAUDE.md` or an explicit request.
Upstream has more skills (`animate`, `pick-ui-library`, `prototype`, …); install them with
`npx skills@latest add emilkowalski/skills`.
